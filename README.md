# MPAZ PRO 3° - Aplicación Móvil Escuela Marcela Paz

Aplicación móvil desarrollada en **Kotlin** y **Jetpack Compose** para Android Studio, diseñada para la gestión de contenidos y actividades educativas de la Escuela Escritora Marcela Paz.

## 🚀 Requerimientos y Funcionalidades
* **RF05 - ViewModel e Integración:** Control de estados, persistencia de datos local con Room y lógica de negocio para la plataforma.
* **Autenticación y Roles:** Módulos de ingreso con vistas para:
  * Jefatura UTP
  * Docente de 3° Básico
  * Estudiante
* **Persistencia de Datos:** Implementación de entidad, DAO y base de datos local con Room (`Rf05IntentosEntity`, `Rf05IntentosDao`, `Rf05Database`).

---

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Kotlin
* **Entorno de Desarrollo:** Android Studio
* **Interfaz de Usuario:** Jetpack Compose
* **Base de Datos Local:** Room Database
* **Control de Versiones:** Git & GitHub / GitHub Desktop
